HTML Tags I Have Learnt

<blockquote>
Used for a longer quotation taken from another source.
<cite>
Marks the title or source of a quote or creative work.
<img>
Displays an image on the page. It needs a src for the file path and alt text that describes the image.
<a>
Creates a link to another page or website using the href attribute.
<nav>
Holds the main navigation links of a website.
